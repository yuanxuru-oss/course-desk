【一、先说结论:怎么打开】

  ❌ 不要双击 index.html —— 一定是白屏,这不是包坏了

     浏览器会拦截 file:// 下的模块脚本、IndexedDB 也用不了,
     所以必须通过「本地服务器」打开。

  ✅ 正确做法:双击下面这个文件

     Windows → 双击「启动课程桌.bat」
     macOS   → 双击「启动课程桌.command」
                (首次提示「无法打开」时:右键 → 打开 → 再点「打开」)

     Linux   → 终端里执行  node serve.mjs  或  python3 serve.py

     它会自动:
       1. 起一个本地服务(默认 http://localhost:4173)
       2. 自动打开浏览器
       3. 端口被占用就自动往后找(4173 → 4174 → …)

     不需要装任何东西:
       Windows 用系统自带的 PowerShell
       macOS / Linux 用系统自带的 Python 3
       装了 Node.js 的话会自动优先用 Node.js(最快)


【二、装成桌面 App】

  浏览器打开后:

     Chrome / Edge → 地址栏右侧会出现「安装」图标 → 点它 → 安装
     Safari(macOS)→ 文件 → 添加到程序坞
     iPhone        → 分享 → 添加到主屏幕
     Android       → 菜单 → 安装应用

  装完就有:独立图标 + 全屏窗口 + 离线可用 + 到点通知。


【三、想部署到网上(手机也能用)】

  拿到的如果是「在线网址」,直接用浏览器打开就能用 ——
  手机上打开后「添加到主屏幕」,就是一个独立 App(离线可用、到点通知)。

  自己部署的话,把 dist 里的全部文件传到任意静态托管即可:

     Vercel / Netlify / GitHub Pages / Cloudflare Pages
     或者自己的服务器 + nginx

  注意两点:
     1. 必须是 https://,否则离线缓存和通知都不生效
     2. 现在这个包用的是相对路径,放在域名根目录或任意子目录都行


【四、数据在哪】

  全部在这台设备浏览器的 IndexedDB 里,不上传任何服务器。
  换设备用「设置 → 导出备份」拿到 JSON,再在另一台导入。


【五、遇到问题】

  · 端口被占用
    启动器会自动换端口,看窗口里打印的地址就行。

  · 双击 .bat 闪一下就没了
    右键「启动课程桌.bat」→「以管理员身份运行」。

  · macOS 提示「无法验证开发者」
    右键「启动课程桌.command」→ 打开 → 再点「打开」。

  · 页面能开但没有「安装」图标
    必须通过 http://localhost 打开(不是 file://),
    且用 Chrome / Edge;Safari 请用「添加到程序坞」。
